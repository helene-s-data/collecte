# collecte

Projet de collecte et de structuration de données, réalisé pendant ma formation de Data Analyst.

## Ce que fait ce projet

Récupère des données sur un site public, les nettoie et les enregistre en CSV exploitable.

## Structure

| Dossier | Contenu |
|---------|---------|
| `src/` | les scripts de collecte |
| `data/` | les fichiers produits – non versionnés |
| `notebooks/` | les analyses exploratoires |

## Outils

Python · pandas · requests
